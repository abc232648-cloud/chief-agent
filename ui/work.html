What each role can do

RoleDefault access
OwnerManage users, installation settings and authorized domain work.
AdministratorManage installation settings and authorized domain work; manage Managers and Workers within assigned domains.
ManagerRead, request and manage work; create and disable Workers entirely within assigned domains. No global settings or approval authority by default.
WorkerRead and request work within assigned domains. Cannot manage settings, users or approvals by default.

Domain access is shared access within that domain, not a separate private workspace for each person. Roles never bypass agent capabilities, policy, evidence or approval checks.
